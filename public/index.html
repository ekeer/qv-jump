4部署到 Cloudflare Pages

  1. 推送到 GitHub / GitLab 仓库
  2. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git
  3. 构建配置：Framework preset 选 None，Build command 留空，Build output directory 填 .
  4. 点 Save and Deploy，几秒后访问 https://<project>.pages.dev
  5. 微信收款码：在 Pages 项目 Settings → Environment variables 添加 WXP_PAY_URL，值为从微信提取的 wxp:// 收款码链接
⚠️ 微信限制：weixin:// 协议在微信内置浏览器中会被拦截，加好友/扫一扫/视频号接口仅在外部浏览器（Safari/Chrome/系统浏览器）点击有效。但 wxp:// 收款码在微信内外都能弹付款。

本地预览：node dev-preview.mjs 或 npx wrangler pages dev .
